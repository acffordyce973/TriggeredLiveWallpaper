## ✨ Features & Architecture

### 🎛️ Wallpaper Sets & Image Organization
- **Multi-Folder Sets:** Create distinct Wallpaper Sets and associate one or multiple folder sources per set.
- **Flexible Storage Access:** Supports both Android Storage Access Framework (SAF) folder picker and direct filesystem paths (e.g., custom SD card folders).
- **Independent Target Screens:** Evaluate and apply wallpapers independently to the **Home Screen**, **Lock Screen**, or **Both**.
- **Random or Sequential:** Shuffle pictures randomly or cycle through images sequentially.
- **Conflict Detection:** Visual warning engine detects overlapping or conflicting rules between active wallpaper sets to prevent ambiguous evaluations.
- **Interactive Image Label Overlay:** Configurable overlay showing the current image filename and folder name (Top, Center, or Bottom with adjustable DP offset). Tapping the wallpaper or label can directly open the image in your favorite gallery or photo editor via an instant trampoline activity.

---

### 🔍 Supported Conditions (Contextual Filters)

Each Wallpaper Set can specify one or more conditions. The engine continuously evaluates these conditions against the live device state to pick the appropriate set:

| Condition | Options | Description |
| :--- | :--- | :--- |
| **Target Screen** | `Home`, `Lock`, `Both` | Direct wallpapers to the home screen, lock screen, or both. |
| **Orientation** | `Any`, `Portrait`, `Landscape` | Restrict sets to specific screen orientations (ideal for landscape tablet docks). |
| **Fold State** | `Any`, `Folded`, `Unfolded`, `Half-Opened` | Detect foldable device postures using Jetpack WindowManager (e.g., Galaxy Z Fold outer vs. inner display). |
| **Charging State** | `Any`, `Charging`, `Discharging` | Activate sets only while connected to power or running on battery. |
| **Time Window** | Start Time – End Time | Set active hours (e.g., `09:00` to `17:00`). Fully supports overnight ranges that cross midnight (e.g., `22:00` to `06:00`). |
| **Days of Week** | Monday – Sunday | Filter sets by specific days of the week (e.g., weekend-only wallpapers). |
| **Months of Year**| January – December | Apply seasonal wallpapers (e.g., October Halloween sets, December holiday sets). |
| **Geofence Area** | Inside / Outside Geofence | Trigger sets when entering or leaving defined geographic locations. Includes an interactive OpenStreetMap (OSM) picker with search and radius configuration. |

---

### ⚡ Supported Triggers (Events)

Triggers determine *when* the wallpaper engine checks conditions and advances the wallpaper image:

- **Timed Interval:** Automatically transitions wallpaper every *N* minutes (powered by exact alarms and WorkManager).
- **Screen On / Unlock:** Switches wallpaper immediately when you turn on the screen or wake the device.
- **Double-Tap:** Double-tap anywhere on an empty area of your home screen to shuffle to the next image.
- **Device Rotation:** Triggers an immediate re-evaluation and wallpaper change when rotating between portrait and landscape.
- **Fold / Unfold:** Immediately switches wallpapers when opening or closing a foldable device.
- **Charger Connect / Disconnect:** Reacts instantly when plugging in or unplugging power.
- **Quick Settings Tile - Wallpaper Override:** Toggle quick tile to lock or force a specific wallpaper set.
- **Quick Settings Tile - Next Wallpaper:** Tap the Quick Settings tile in your notification shade to jump to the next image instantly.
- **Notification Action Button:** Optional persistent notification with a one-tap "Next Wallpaper" button.
- **External Broadcast Intent:** Trigger wallpaper shuffles from automation tools (Tasker, Automate, ADB) using broadcast action:
  ```bash
  adb shell am broadcast -a com.antigravity.triggeredwallpaper.TRIGGER_NEXT
  ```

## 🔒 Permissions & Privacy

Triggered Live Wallpaper operates **100% offline and locally on your device**. No personal data, location telemetry, or images are ever transmitted to any external server.

The table below explains why each declared permission in `AndroidManifest.xml` is required:

| Permission | Purpose & Justification |
| :--- | :--- |
| `android.permission.SET_WALLPAPER` | Required by the Android Wallpaper framework to bind and set wallpaper properties. |
| `android.permission.INTERNET` | Required exclusively by the OpenStreetMap (OSM) tile downloader to display map tiles when selecting and configuring Geofences in the map picker. |
| `android.permission.ACCESS_NETWORK_STATE` | Checks network availability prior to requesting OpenStreetMap tiles to prevent redundant network failures. |
| `android.permission.WAKE_LOCK` | Briefly wakes the CPU when exact timed alarms fire so wallpaper transitions execute on time even when the device is in deep Doze mode. |
| `android.permission.RECEIVE_BOOT_COMPLETED` | Automatically re-schedules exact interval alarms and restores wallpaper monitoring services after device reboot. |
| `android.permission.SCHEDULE_EXACT_ALARM` | Required on Android 12+ (API 31+) to schedule exact time window changes and interval wallpaper transitions. |
| `android.permission.USE_EXACT_ALARM` | Allows reliable scheduling of exact alarms on Android 13+ (API 33+). |
| `android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Allows prompting to exempt the wallpaper service from aggressive OEM background kills and app hibernation. |
| `android.permission.ACCESS_FINE_LOCATION` | Required to query precise GPS coordinates when testing whether the device is inside a user-configured Geofence. |
| `android.permission.ACCESS_COARSE_LOCATION` | Required as base location permission for network and cell-tower location checks. |
| `android.permission.ACCESS_BACKGROUND_LOCATION` | Allows evaluating Geofences when the device screen is off or when the app UI is closed in the background. |
| `android.permission.READ_MEDIA_IMAGES` | Required on Android 13+ (API 33+) to read user photos and wallpaper directories. |
| `android.permission.READ_EXTERNAL_STORAGE` | Required on Android 12 and below (API ≤ 32) to read images from shared storage. |
| `android.permission.MANAGE_EXTERNAL_STORAGE` | "All files access" permission, allowing direct filesystem path access to user folders (e.g. `/sdcard/Wallpapers`) without Storage Access Framework tree traversal bottlenecks. |
| `android.permission.POST_NOTIFICATIONS` | Required on Android 13+ (API 33+) to display the optional persistent status notification and the "Next Wallpaper" action button. |
